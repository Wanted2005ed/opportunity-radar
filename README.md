# Opportunity Radar

**Find opportunities before they find everyone else.**

Opportunity Radar is a mobile-first opportunity discovery product for students, freelancers and entrepreneurs. It is designed to aggregate public opportunities, rank them with AI-assisted signals, and help users act faster.

## Current status

This repository contains the production-ready static frontend prototype. The opportunity cards currently use **clearly labeled demo data**. No live opportunity, deadline, organization, statistic or testimonial is fabricated.

## Planned product

- Jobs and remote work
- Freelance gigs
- Scholarships and grants
- Competitions
- Startup and business opportunities
- Search and category filtering
- Personalized profiles and alerts
- Saved opportunities and application tracking
- Paystack subscriptions
