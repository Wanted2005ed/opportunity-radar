# Opportunity ingestion policy\n\n1. Discover from permitted public APIs, feeds, connected apps, or official public pages.\n2. Preserve the original canonical URL and source attribution.\n3. Deduplicate by canonical URL and normalized title/source.\n4. Extract country/region, employment type, deadline when present, age restrictions, and eligibility notes.\n5. Employment opportunities default to 18+ unless the source explicitly states a different eligible age.\n6. Imported records remain `needs_review` until a trust check is completed.\n7. Suspicious, expired, broken, or unverifiable listings must not enter the verified public feed.\n8. Never bypass login walls, CAPTCHAs, anti-bot controls, or source restrictions.\n9. Respect source-specific API limits and attribution requirements.\n
