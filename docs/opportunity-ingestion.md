# Opportunity Radar automated ingestion\n\nOpportunity Radar now has a server-side ingestion function that collects public job listings from Jobicy and Arbeitnow, normalizes them into the existing `opportunities` schema, deduplicates by canonical source URL, and upserts them into Supabase.\n\n## Trust policy\n\nImported employment listings are **not automatically marked verified**. They enter the database with `verification_status = needs_review`, `verified = false`, and `minimum_age = 18`. This keeps unreviewed listings out of the public verified feed while preserving them for an admin review queue.\n\n## Refresh\n\nThe Supabase Edge Function is named `opportunity-ingest`. The intended production refresh cadence is hourly or a few times per day, subject to source terms and rate limits.\n\n## Sources\n\n- Jobicy public Jobs API: https://jobicy.com/api/v2/remote-jobs\n- Arbeitnow public Job Board API: https://www.arbeitnow.com/api/job-board-api\n\nSource attribution and canonical URLs must remain visible when listings are eventually published.\n\n## Next source adapters\n\nComposio-connected sources such as Dice, ZipRecruiter, Gmail opportunity alerts, and public web discovery can be added as separate adapters. They should feed the same normalization/review pipeline rather than writing directly to the public verified feed.\n
